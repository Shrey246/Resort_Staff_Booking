# Tusk & Dawn - Staff Booking Console

Official staff booking console and real-time room availability management system for **Tusk & Dawn**.

## Features
- **Real-Time Room Matrix & Availability**: Instant tracking of Valley Cottages, Hill Top Rooms, and Dormitories.
- **Direct Staff Booking Operations**: Rapid booking creation, room status updates, and modifications.
- **Cross-Device Real-Time Sync**: MQTT WebSocket synchronization across front desk terminals and mobile devices.
- **Staff Roster & Activity Logs**: Comprehensive audit trail with logged staff actions and shift tracking.
- **Offline PWA Support**: Service worker caching and installable web app experience.
