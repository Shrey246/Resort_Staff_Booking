🔗 Backend API Configuration

Connect your custom Node.js, Express, Django, FastAPI, or PHP backend. When configured, all room bookings, updates, and cancellations sync to your server in real time.

POST /api/bookings C - CREATE

Creates a new room booking in your database with room ID, guest name, contact, and check-in / check-out times.

Request Payload (JSON) 
{
  "roomId": "VC-1",
  "roomName": "Valley Cottage 101",
  "date": "2026-10-17",
  "checkInTime": "02:00 PM",
  "checkOutTime": "11:00 AM",
  "guestName": "Jane Doe",
  "guestPhone": "+1 555-0199",
  "notes": "Late arrival requested",
  "bookedBy": "Staff 1"
}
PUT /api/bookings/:id U - UPDATE

Updates an existing room booking (guest name, contact, check-in / check-out timings, or notes).

Request Payload (JSON) 
{
  "guestName": "Jane Doe",
  "guestPhone": "+1 555-0199",
  "checkInTime": "03:00 PM",
  "checkOutTime": "12:00 PM",
  "notes": "Updated check-in time per phone request"
}
DELETE /api/bookings/:id D - DELETE / CANCEL

Cancels and removes a room reservation from the database.

Request Payload (JSON) 
{
  "cancelledBy": "Staff 1",
  "reason": "Guest cancellation request"
}
GET /api/bookings?date=YYYY-MM-DD R - READ / LIST

Retrieves all active bookings for a specific calendar date or entire inventory.
